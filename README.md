# MESBG Fight Calculator

Exact odds for a fight in the Middle-earth Strategy Battle Game (2024 rules):
who wins the duel, and how many wounds the winner deals.

Live page: https://conrad-n.github.io/mesbg-calc/

- `index.html` — the page
- `engine.js` — exact odds calculation
- `sim.js` — random dice simulator, only used to cross-check the engine
- `test.js` — run `node test.js`
